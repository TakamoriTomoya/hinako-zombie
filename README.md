# ゾンビひなこシューティング

夜の町で、ゾンビになって歩いてくるひなこを銃で撃って倒す一人称ガンシューティング。
[ひなこシューティング](https://github.com/TakamoriTomoya/hinako-shooting) の写真・音・画面のしくみを元にしている。

あそぶ: https://hinako-zombie.vercel.app
(`main` に push すると Vercel に自動でデプロイされる)

```sh
npm install
npm run dev    # 開発サーバー
npm run build  # 本番ビルド(dist/)
npm test       # テスト
npm run lint
```

## あそびかた

- 町の中を自由に歩き回りながら、追いかけてくるゾンビひなこを撃つ
- 操作
  - 歩く: 左下のスティック(PCは WASD / ↑↓ キー)
  - 向きを変える: 画面をドラッグ。左右に回れて、上下も少し見られる(PCは ← → / Q E キーでも)
  - 撃つ: タップ / クリック。ハンドガンは弾切れなしで、ずっと撃てる(指を離した時に撃つ。動かすとドラッグになる)。頭に当てるとふつうのゾンビは一発
  - 武器の持ちかえ: 右下のボタンか 1〜7 キー
  - 一時停止: 左上のボタンか Esc / P キー(つづける・さいしょから・タイトルへ・音のオン/オフ)。ほかのアプリに切りかえても自動で止まる
- ゾンビは霧の奥・建物のすき間・家やお店のドア・車や木のかげ・地面の下から出てきて、追いかけてくる。
  目の前で赤く光って「!!」が出たらかみつかれる(ライフ -1)。その前に倒すか、下がってよける
- 画面の外(横やうしろ)にいるゾンビは、画面のはしの矢印で知らせる
- 建物のうしろに隠れているゾンビは見えないし、撃っても建物に当たる
- 倒したゾンビがたまにハートを落とす。撃つか上を歩くと拾えて、ライフが1ふえる(満タンの時は500点)
- 落ちている武器の箱を撃つか、上を歩くと拾える(拾っても持ちかえない)。弾がなくなるとハンドガンに戻る
  - マシンガン: 動かさずに押し続けている間、撃ち続ける
  - ショットガン: 1発で7つの弾が広がって飛ぶ。近くの敵に強い
  - スナイパー: 1発がとても強く、ならんだゾンビを3体までつらぬく
  - かえんほうしゃき: 押し続けている間、ねらった方向の前方5mを焼く(焼かれている間ゾンビは止まる)
  - ロケラン: 当たったところが爆発して、まわりのゾンビもまとめて倒せる
  - しゅりゅうだん: ねらった地面へ山なりに投げて、落ちたところで爆発する
- ゾンビは、場所の中の決まった地点(スタート・途中・出口の手前)を通ると、その場で3〜5体出てくる(ステージが進むと多くなる)。
  立ち止まっていれば新しくは出てこない。倒しきってまだ先に地点がある時は「まえに すすもう!」と黄色の矢印で知らせる
- 1ステージは3つの場所を順に進む。全部の地点を通ってゾンビを倒しきると出口に「つぎへ」が出るので、歩いていくと次の場所へ。3つ目の場所ではボスが来る
  - STAGE 1: 住宅街の曲がり角 → 公園 → 学校前のT字路
  - STAGE 2: 商店街の交差点 → スーパーの駐車場 → 商店街のゲート
  - STAGE 3: 駅前のバスのりば → ガード下 → 駅の正面(ボスは駅の中から出てくる)
  - 場所の形(建物・ドア・車・歩ける範囲・出口など)は `src/lib/scenes.ts`
- ボスはがれきを投げてくる(落ちてくる所に赤い輪が出るので、歩いてよける。撃ち落とすこともできる)。ときどき突進してくる(たくさん当てるとひるむ)

## 音楽について

BGM・ジングルは SketchyLogic さんの [NES Shooter Music (5 tracks, 3 jingles)](https://opengameart.org/content/nes-shooter-music-5-tracks-3-jingles)（CC0）を使っています。
効果音はコードで合成しています（`src/lib/sound.ts`）。

## 写真について

このリポジトリの写真（`public/images/` など）は実在の人物を撮影したものです。
写真の著作権・肖像権は撮影者と被写体本人にあります。
このゲームで遊ぶ以外の目的での利用・転載・加工・再配布はしないでください。
